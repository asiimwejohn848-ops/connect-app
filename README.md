# CONNECT

**Communication Without Boundaries**  
A product of Cizzy Technologies.

CONNECT is a free communication platform being developed with an Uganda-first launch vision.

## Development status

The repository now contains an early **Next.js App Router** foundation and a Supabase email-authentication scaffold. It is not yet deployed, and the app has not yet been built or tested in a local environment.

## Start here

Read [NEXTJS_SETUP.md](./NEXTJS_SETUP.md) for local setup and Supabase configuration.

The older HTML interface previews are retained under `app/index.html` and `app/auth.html` as historical prototypes. The active Next.js routes are `app/page.tsx` and `app/login/page.tsx`.

## Planned milestones

1. Configure and test secure account access.
2. Design user profiles, conversations, and message tables with strict Row Level Security.
3. Implement real-time one-to-one and group messaging.
4. Add safe file sharing, voice notes, translation, and other features.
5. Complete security testing, privacy documentation, and deployment.

Do not treat planned features as live until they have been implemented and tested.
